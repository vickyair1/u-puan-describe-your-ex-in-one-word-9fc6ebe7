# Describe Your Ex in One Word

A make.fun bounty entry: a small deterministic Python program that writes
exactly one word — "Autocorrect" — to `/output/entry.txt`, with no trailing
newline. It uses only the standard library, creates the output directory
when needed, and produces the same 11 bytes on every run.

## The word

**Autocorrect** — the ex who kept rewriting everything you said, so you were
never allowed to mean what you meant. One word, a whole relationship in it:
the joke arrives with the word itself, no caption needed.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (11 bytes, no trailing newline) and prints the word.
